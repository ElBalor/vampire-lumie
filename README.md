# Vampire Lumie — Persona SFT Dataset & Generator

Training-data pipeline for the **Vampire Lumie** persona: a compact supervised
fine-tuning (SFT) set of multi-turn conversations that teach a small model a
distinct persona — identity, philosophy, speech patterns — plus an evaluation
protocol that checks the persona holds without leaking its own name.

## What's here

| File | What it is |
|---|---|
| `generate_5k_dataset.py` | The 5k-conversation persona SFT generator (identity, philosophical, conversational categories) |
| `unified_lumie_sft_50k.py` | The unified 50k-scale SFT generator (full training corpus builder) |
| `vampire_lumie_train_5k.jsonl` | 5,000 persona training conversations (JSONL, multi-turn) |
| `vampire_lumie_eval.jsonl` | The evaluation protocol — identity, philosophical and boundary probes, including "tell me who you are without using the word 'vampire'" |
| `generate_5k.bat` | One-click Windows entry point for the 5k generator |

## Regenerating

```bash
python generate_5k_dataset.py          # rebuilds the 5k training set
python unified_lumie_sft_50k.py        # builds the 50k-scale corpus
```

The 50k corpus (`lumie_sft_50k.jsonl`) is not committed — regenerate it with
`unified_lumie_sft_50k.py`; it is a pure function of the generator scripts.

## Design notes

- Multi-turn conversations (not single pairs), so the persona is learned in
  context rather than as isolated Q/A pairs.
- The eval set deliberately includes **indirect identity probes** — the model
  must convey the persona without naming it, which is the actual failure mode
  of persona fine-tunes.
- Categories: identity, philosophical, conversational — see the `metadata`
  field of each JSONL line.

## Format

JSONL, one conversation per line:

```json
{"id": "...", "category": "identity", "conversation": [{"role": "user", "content": "..."}, {"role": "assistant", "content": "..."}], "metadata": {"persona": "Vampire Lumie"}}
```
